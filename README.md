# Bloom & Brew Café — React + Vite

This is the React/Vite version of the Bloom & Brew Café academic Digital Marketing project.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Vite will show a local address, normally:

```text
http://localhost:5173/
```

Open that address in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Project features

- React 18
- Vite
- React Router
- Responsive design
- Home, Menu, Blog and Contact pages
- Interactive menu category filters
- Front-end contact form demo
- SEO meta tags
- Internal navigation
- Digital-marketing-focused sample content

## Important

Bloom & Brew Café is a fictional brand created for an academic project. The contact information and performance-related content are demonstration data and should not be presented as real business results.
